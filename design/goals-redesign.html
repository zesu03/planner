Goals — redesign options
Four directions for the Goals list, drawn to scale in the live Sand & Jade palette with real category colours. Content is representative (a 6-goal portfolio). Pick one — or mix (e.g. “Option 1 hero + Option 3 cards”) — and I’ll build it. Mobile behaviour is shown/annotated under each. The New-goal form is unchanged for now (per your note).
Option 1 · recommended
Portfolio grid — summary hero + card tiles
A summary hero (overall progress ring + at-a-glance counts) crowns the page, then goals flow as a responsive grid of cards that fills the desktop width and scales as you add more. Keeps today’s tap-card → detail flow, so it’s the lowest-risk of the ambitious options. Highest visual impact.

Option 2
Two-pane workspace — list + live detail
A compact goal list on the left; the selected goal opens inline on the right (Linear / Things feel). Best use of desktop width and no navigation jump between list and detail. Biggest change — it folds the current GoalDetail view into this pane — and on mobile it falls back to today’s list → full-screen detail.

Option 3
Refined column — polish, don’t rebuild
Keeps today’s single vertical list but takes it to a top-notch finish: a centered ~760px column so it doesn’t stretch, serif goal titles, tokenised spacing, richer cards, a slim triage line, and no emoji. Lowest risk, quickest to ship, and the closest to what you already have.
